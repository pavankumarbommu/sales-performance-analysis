# Sales Performance Analysis Dashboard

## Project Overview
This project focuses on building an interactive Sales Performance Dashboard using Power BI to analyze business performance across sales, profit, and regional dimensions. The dashboard enables data-driven decision-making by presenting clear insights into sales trends, category performance, and geographical distribution.

The objective of this project is to convert raw sales data into meaningful visual insights using industry-standard data modeling and visualization practices.

---

## Tools and Technologies
- Power BI  
- DAX (Data Analysis Expressions)  
- Power Query  
- Microsoft Excel  

---

## Key Features
- KPI analysis including Total Sales, Total Profit, Quantity Sold, and Profit Margin  
- Month-wise and year-wise sales trend analysis  
- Category-wise and city-wise performance evaluation  
- Interactive filters for dynamic data exploration  
- Executive-style dashboard design for business reporting  

---

## Dashboard Insights
- Sales consistently peak during the fourth quarter across years  
- Technology and Furniture categories contribute the highest revenue  
- A limited number of cities generate the majority of total sales  
- Profit margins remain stable across different time periods
